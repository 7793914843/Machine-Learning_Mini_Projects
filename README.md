# 🤖 Machine Learning Mini Projects

A collection of **10 beginner-friendly Machine Learning projects** built using **Python and Scikit-learn**. These projects helped me practice data preprocessing, exploratory data analysis, model training, prediction, and evaluation.

## 📌 Projects

1. 🏠 **House Price Prediction** – Predict house prices using regression.
2. 🎓 **Student Performance Prediction** – Predict student performance based on academic factors.
3. 📧 **Spam Email Detection** – Classify messages as spam or not spam.
4. 🩺 **Diabetes Prediction** – Predict whether a person is likely to have diabetes.
5. ❤️ **Heart Disease Prediction** – Predict the possibility of heart disease.
6. 👥 **Customer Churn Prediction** – Predict whether a customer is likely to leave a service.
7. 🎬 **Movie Recommendation System** – Recommend movies based on user preferences.
8. 🌸 **Iris Flower Classification** – Classify iris flowers into different species.
9. 💰 **Loan Approval Prediction** – Predict whether a loan application will be approved.
10. 📈 **Sales Prediction** – Predict future sales using historical data.

## 🛠️ Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn
* Machine Learning

## 🎯 What I Learned

Through these projects, I practiced:

* Data cleaning and preprocessing
* Handling categorical data
* Feature selection
* Train-test splitting
* Data visualization
* Regression and classification
* Model training and prediction
* Model evaluation
